# 基于uniapp的计算器
## 语言：vue3+typescript
## 功能列表
1. 加减乘除
2. 函数计算
3. 时钟
4. 日历
5. 天气
6. 小游戏
## 功能导航
首页是计算器，点击计算器三个字跳转到时钟页面，点击时钟二字跳转到日历页面，点击日历二个字跳转到天气页面，天气页面需要授权位置信息，然后显示当前位置的天气。当然也可以点击切换城市查看其他城市天气。天气界面点击AQI的查看详情可以查看AQI指数，点击查看40日预报跳转到40日预报界面。<br/>
计算器界面有左右两个按钮，左边是计算器，右边是休息一下。左滑计算器界面可以进入高级计算器，能够计算函数的值。<br/>
计算器右边是休息一下，点击后可以玩游戏。俄罗斯方块和贪吃蛇。
## 运行方式
1. 下载本项目
2. 下载HBuilderX
3. 在HBuilderX中打开本项目
4. 连接真机或模拟器
5. 运行项目
